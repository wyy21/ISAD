@startuml 修改用户名或密码时序图
actor 用户
participant "小程序前端" as MiniApp
participant "后端服务" as Server
participant "用户数据库" as DB

用户 -> MiniApp: 进入账号修改页，填写原密码、新用户名/密码
MiniApp -> Server: 发起修改请求(token+原密码+新账号信息)
Server -> Server: 校验登录token是否有效
alt token无效
    Server --> MiniApp: 返回【未登录，请重新登录】
    MiniApp --> 用户: 提示登录失效
else token有效
    Server -> DB: 查询该用户记录
    DB --> Server: 返回用户存储信息
    Server -> Server: 比对原密码哈希
    alt 原密码错误
        Server --> MiniApp: 返回【原密码不正确】
        MiniApp --> 用户: 提示密码错误
    else 原密码正确
        Server -> DB: 更新用户名/密码（密码加盐哈希）
        DB --> Server: 更新成功
        Server --> MiniApp: 返回修改成功
        MiniApp --> 用户: 提示修改完成，刷新页面
    end
end
@enduml

@startuml 借书时序图
actor 读者
participant "前台小程序/页面" as View
participant "借阅服务" as BorrowService
participant "图书服务" as BookService
participant "用户服务" as UserService
participant "数据库" as DB

读者 -> View: 扫码/输入图书编号借书
View -> BorrowService: 发起借书请求(读者ID,图书ID)
BorrowService -> UserService: 校验读者账号状态、是否欠费
UserService --> BorrowService: 账号正常
BorrowService -> BookService: 查询图书库存与是否可借
BookService --> BorrowService: 图书在馆可借
BorrowService -> DB: 创建借阅记录，修改图书状态为已借出
DB --> BorrowService: 写入成功
BorrowService --> View: 借书成功
View --> 读者: 提示借书成功，展示归还日期
@enduml
